# 👤 Ready Player Me 3D Avatar Setup

Place your custom 3D female avatar model in this directory!

## 📁 File Location
```
frontend/avatars/avatar.glb
```

## 🛠️ How to Create & Export Your Ready Player Me Avatar:
1. Visit **[https://readyplayer.me](https://readyplayer.me)**.
2. Design your custom female avatar with clothing, hair, and style.
3. Export or download the avatar as a **`.glb`** file.
4. Rename the downloaded file to **`avatar.glb`** and place it in this directory (`frontend/avatars/avatar.glb`).
5. Ensure your avatar export includes morph targets for ARKit and Oculus visemes (standard on Ready Player Me).

> **Automatic Fallback:**
> If `avatar.glb` is not present in this folder, CampusMind AI automatically loads an official Ready Player Me female avatar from the official CDN so the 3D assistant works seamlessly right out of the box!
