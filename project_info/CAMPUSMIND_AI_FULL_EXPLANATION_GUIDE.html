CampusMind AI — Full Project & Code Architecture Guide

A Complete Technical Breakdown, Code Walkthrough, RAG Pipeline Flow, and Viva/Interview Guide for College Project Presentation.

1. Project Overview & Actual Purpose (Kya Hai Ye Project?)

CampusMind AI ek Enterprise-Grade Intelligent Smart Campus Platform hai jise VPCSC Indapur (Affiliated to Savitribai Phule Pune University — SPPU) ke students, faculty aur administrative staff ke liye banaya gaya hai.

🎯 Main Goal: Traditional colleges me students ko syllabus, exam timetables, fee window counters, HOD details aur circulars ke liye alag-alag notices dekhne padte hain ya line lagani padti hai. CampusMind AI ek hi platform par in sabhi ko Grounded AI + Voice Interaction + Role-Based Dashboards + Cloud Sync ke sath solve karta hai.

Key Real-World Problems Solved:

  • Zero AI Hallucination (Grounded RAG): Normal AI (ChatGPT) college ke imaginary rules guess karta hai. Lekin CampusMind AI college ke official PDF circulars aur SPPU syllabus ko pehle scan karta hai aur sirf verified documents se hi 100% accurate jawab deta hai.
  • Degree & Year-Aware Personalized Cockpit: Student jis bhi program ka hai (e.g. BBA(CA) 3rd Year ya BCS 1st Year), dashboard uske year ke subjects, teachers aur exam timetables automatically dikhata hai.
  • Voice Accessibility (Speech-to-Text & TTS): Student direct bol kar (Voice typing se) question puchh sakta hai aur AI ke answers ko sun (Listen audio) bhi sakta hai.
  • Mathematical & SPPU Academic Calculations: CGPA to percentage conversion, 75% attendance target tracker, marks split up, time complexity aur networking subnetting directly solve karta hai.
  • Dual Cloud & Local Storage: Supabase PostgreSQL Cloud Database + Local SQLite backup.

2. High-Level Architecture & End-to-End Request Flow

Poora project 3 Main Layers me structured hai:

1

Frontend UI Layer

HTML5, Modern CSS Glassmorphism, React 18 (Dashboards), Web Speech API (Voice), HTML5 Canvas (Image compression).

2

Backend & AI Layer

Python Flask REST API, PyJWT (Token Security), Dense Vector Embeddings, RAG Retrieval Engine, OpenRouter AI.

3

Database & Cloud Storage

Supabase PostgreSQL Cloud DB (public.users) + Local SQLite (campusmind.db) + Uploaded PDF files.

How a Chat Query Travels Through the System (End-to-End Flow):

  1. User Query Input: Student browser me message likhta hai ya mic daba kar bolta hai (Web Speech API).
  2. Authentication Check: Browser local storage se JWT Token attach karta hai (`Authorization: Bearer <token>`).
  3. Backend Processing (`/api/chatbot/chat`): Flask API request receive karta hai aur user ka role aur academic year detect karta hai.
  4. RAG Vector Semantic Search: User ke question ko 384-dimensional vector me convert kiya jata hai aur official college PDF documents ke chunks se Cosine Similarity match kiya jata hai.
  5. Augmented AI Inference: Top retrieved verified context + Persona system prompt ko OpenRouter (NVIDIA Nemotron 3.5 AI) ko bheja jata hai.
  6. Grounded Response & Citations: AI jawab generate karta hai. Frontend par verified source citations, Listen button, Copy, Edit aur Resend options ke sath render hota hai.

3. Detailed Codebase & Module-by-Module Explanation

Aayiye har ek major file aur uske andar likhe code ka actual purpose samajhte hain:

A. Backend Files (Python + Flask)

bakend/app.py

Purpose: Backend ka Main Entry Point aur Flask Application Factory.

  • Flask server initialize karta hai, CORS security enable karta hai.
  • Sabhi routes blueprints ko register karta hai (/api/auth, /api/student, /api/chatbot, /api/admin).
  • Health check endpoint (GET /api/health) provide karta hai jo Supabase connection, AI engine aur DB status return karta hai.
bakend/services/openrouter_service.py

Purpose: AI Chatbot Engine & VPCSC Persona Prompts.

  • OpenRouter API ke through nvidia/nemotron-3.5-lightning:free model ko connect karta hai.
  • get_persona_system_prompt(): Isme VPCSC Indapur ki official leadership (Principal Dr. Lalasaheb Kashid, HODs: Prof. Kaldate, Prof. Bhong, Prof. Shaikh, Window 1, 2, 3 details) hardcoded foundation truth ke roop me configured hai.
  • Multimodal vision support (agar student question ke sath image/document upload kare).
bakend/services/rag_service.py & embedding_service.py

Purpose: Document Chunking, 384-d Embeddings & Cosine Retrieval.

  • chunk_text(): Badi PDF files ko 600 characters ke small chunks me divide karta hai (120 char overlap ke sath taaki context na toote).
  • compute_embeddings(): Text chunks ko 384-dimensional dense vectors me convert karta hai.
  • search_similar_chunks(): User ke question aur document chunks ke beech mathematical Cosine Similarity calculate karke sabse relevant verified excerpts retrieve karta hai.
bakend/services/user_service.py & database.py

Purpose: Dual-Engine Cloud & Local User Management.

  • create_user(): New user create karte samay password ko generate_password_hash (PBKDF2 SHA256) se encrypt karta hai.
  • Supabase + SQLite Sync: Data ko pehle Supabase Cloud PostgreSQL (public.users) me insert karta hai aur local campusmind.db me backup rakhta hai.
  • Passcode Security: Admin ke liye VPCSC@ADMIN2026 aur Faculty ke liye VPCSC@FAC2026 passcodes verify karta hai.
  • generate_token(): Cryptographically signed JWT Token generate karta hai jisme user ka role aur academic year embed hota hai.

B. Frontend Files (HTML + CSS + JavaScript)

frontend/pages/chat.html & frontend/js/chatbot.js

Purpose: Full AI Chatbot Interface, Voice Speech Engine & Message Toolbars.

  • Voice Speech-to-Text: window.SpeechRecognition use karke real-time voice typing input karta hai. Mic active hone par red glowing pulse animation chalti hai.
  • Voice Text-to-Speech: window.speechSynthesis use karke bot ke answer ko bol kar sunata hai (Listen button).
  • Copy, Edit & Resend Toolbar: Har user question par Copy (clipboard), Inline Edit (editable box with Save & Resend), aur Resend buttons hain.
  • Custom Profile Photo Rendering: Chat header status badge aur user message bubble ke sath student ki custom uploaded photo display hoti hai.
frontend/pages/student-dashboard.html & frontend/js/script.js

Purpose: Student Cockpit & Custom Profile Photo Upload.

  • React 18 Component Architecture: Student dashboard dynamic React state par chalta hai. Program switch karne par (`BBA(CA)`, `BCS`, `BBA`, etc.) bina page reload hue subjects aur exam timetables switch ho jaate hain.
  • HTML5 Canvas Image Compression: Edit Profile modal me student jab apne device se photo choose karta hai, browser in-memory <canvas> ke through image ko 280px par resize aur 0.85 quality JPEG me compress karke base64 data URL banata hai. Isse cloud database par koi heavy load nahi padta.
  • Profile Details Modal: Navbar me profile photo par click karne par student details, PRN ID, college name, aur Edit option open hota hai.

5. College Viva / Project Presentation Q&A (Examiner Questions)

College exam ya project presentation me teachers aapse ye questions puchh sakte hain. Inke exact technical answers:

Q1: "Aapke chatbot aur ChatGPT me kya difference hai?"

Answer: ChatGPT ek general LLM hai jo specific college ke rules, HODs, window helpdesks aur exact syllabus nahi jaanta aur guess (hallucinate) karta hai. Hamara project Retrieval-Augmented Generation (RAG) use karta hai jo pehle VPCSC Indapur aur SPPU ke verified PDF circulars ko search karta hai aur sirf unhi se factual answer with source citations deta hai.

Q2: "RAG kaise kaam karta hai aapke project me?"

Answer: RAG 3 steps me kaam karta hai: (1) Ingestion: College PDFs ko 600-character chunks me break karke 384-dimensional dense vector embeddings banate hain. (2) Retrieval: User question ko vectorize karke Cosine Similarity se top relevant chunks match karte hain. (3) Generation: Retrieved official chunks ko system prompt ke sath OpenRouter AI ko pass karke accurate answer generate karte hain.

Q3: "Profile photo upload kaise handle kiya hai bina server heavy storage ke?"

Answer: Humne Client-Side HTML5 Canvas Compression use kiya hai. Student jab photo select karta hai, browser client-side canvas me image ko max 280x280 resolution aur 0.85 JPEG quality me optimize karta hai aur base64 data format me Supabase Cloud DB me store karta hai. Isse external S3 bucket ki jarurat nahi padti aur loading super fast hoti hai.

Q4: "Security kaise implement ki hai?"

Answer: Humne industry standard PyJWT (JSON Web Tokens) with HS256 algorithm use kiya hai. Passwords ko Werkzeug PBKDF2 SHA256 hashing se securely encrypt kiya jata hai. Admin aur Faculty signup ke liye college verification passcodes (`VPCSC@ADMIN2026` / `VPCSC@FAC2026`) mandatory hain.
